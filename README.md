# 🎬 Netflix Clone – Frontend Project (HTML + CSS)

A fully responsive **Netflix India Landing Page Clone** built using **HTML5 and CSS3**.  
This project replicates the visual design and layout of Netflix with similar hero area, trending carousel, feature cards, FAQ section, and structured footer.

🌟 This project is created for **learning and front-end development practice** only.  
No backend or API is used — everything is designed manually using CSS styling and layout techniques.

---

## 🖼️ Project Preview

🏠 **Homepage Layout Includes**
| Section | Description |
|--------|-------------|
| Navigation Bar | Netflix logo, Language selector, Sign In button |
| Hero Section | Title, subtitle, email signup form |
| Trending Movies | Horizontal scrolling poster row with ranking badges |
| Feature Cards | Why join Netflix – four card layout |
| FAQ Section | Netflix-style expandable like question blocks |
| Footer | Contact, quick links, country selector |
